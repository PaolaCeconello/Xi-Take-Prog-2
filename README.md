# Xi Take

Jogo 2D de plataforma singleplayer desenvolvido em C usando a biblioteca Allegro 5 para a disciplica de Programação 2, cursado em 2026.1 na Universidade Federal do Paraná.

<img width="1092" height="614" alt="a3-ezgif com-optimize" src="https://github.com/user-attachments/assets/f3fe56d7-62fd-45bc-be10-86644fe150d2" />


## Funcionalidades
- 1 fase única.
- Movimentação de personagem (Direita, Esquerda, Pular e Abaixar).
- Sistema de pontos de vida que diminui conforme colisão com obstaculos/armadilhas.

- Rolling background com efeito paralaxe.
- Armadilhas movéis e estáticas.
- Interação com objetos (Escada interativas). 
- Item coletável que recupera vida.
- Ajuste de volume de trilha sonora.

## Pré-requisitos
- Allegro 5

## Como rodar
```bash
git clone https://github.com/PaolaCeconello/a3.git
cd a3
make
./jogo
```
